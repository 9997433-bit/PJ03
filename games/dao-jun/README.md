# 《道君 · 人生模拟器》

一款纯浏览器文字策略人生模拟器。墨蓝命卷与雷纹贯穿四步创角和主界面；参悟天地道纹、锤炼神魂、选择剑/法/体/神四条道途，并在修真世界争夺灵地与资源，最终走向十二种不同命数。逐掷入册、逐令成链，存档可验不可改。

## 游玩

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。游戏会自动把存档写入浏览器 `localStorage` 的独占键 `daojun_save_v1`，不需要后端服务，也不会与同源部署的其他游戏串档。

角色创建由引擎侧四步状态机约束，当前问题未完成时无法跳步：

1. **留名** — 决定名号
2. **问身** — 山村遗孤、世家旁支、江湖散修、破宗余脉
3. **择途** — 剑途、法途、体途、神途
4. **立誓** — 守土、逍遥、问鼎或止戈

进入命卷后可以执行六种核心行动：

- **悟道**：消耗神魂，获得道纹感悟
- **凝纹**：把足够的感悟凝成永久道纹
- **斗法**：与敌手回合制交锋，争夺玄玉与声望
- **占地**：消耗粮草与灵气，扩张灵地
- **突破**：满足道纹、神魂和领地要求后渡劫
- **调息**：收功静坐，回补气血、灵气与神魂——资源见底时永远还有一条退路

数字键 `1` 到 `6` 可以快速执行对应行动；随机事件出现时，数字键 `1`、`2` 可直接选择。乾坤囊中的物品点击即可使用，右侧「法会」可买卖。

### 斗法：六式回合制

`斗法` 不再是一次判定，而是进入回合制交锋。十二名敌手按境界分层出没，数字键 `1` 到 `6` 对应六式：

| 式 | 效果 |
| --- | --- |
| **力破** | 倾力一击（×1.35），自身门户随之大开（×1.25）；会一并兑现已存的破绽与蓄势 |
| **周旋** | 双方伤害俱减；D20 ≥ 14 看破一处破绽 |
| **布纹** | 弃这一击，耗 6 神魂铺纹；D20 + 调和/10 ≥ 13 存下蓄势，下一记力破威力 ×1.8 |
| **摄神** | 耗 8 神魂以神念攻魂，伤害取自神魂且无视护甲；D20 ≥ 12 另留下一处破绽 |
| **吞丹** | 吞下囊中最强丹药回血，敌手趁隙一击（×1.15） |
| **遁土** | 脱身：D100 ≤ 45 + 威势 − 12×已失败次数；每次失败敌手气焰再涨一成 |

交锋有四种出口：**胜**（玄玉、声望与掉落）、**劫财**（被夺去部分玄玉，重伤但存活）、**夺命**（噬魂老魅一类的敌手只取性命）与**遁**。

### 法会与结局

「法会」按境界解锁货架，售价随品阶递增，回收价为定价的 45%（江湖散修 55%），威势 ≥ 40 享一成折扣。

十二种结局分两类：**六种终局**（陨落、坐化，以及四道途各自的道君之证）自行落定；**六种里程碑**（开疆、纹圣、魂主、巨富、济世、逍遥）改为「道枢垂问」——达标时暂停并询问「就此收官」抑或「继续问道」，谢绝过的里程碑不再垂问。这解决了 R2 审计发现的结局遮蔽：里程碑不再半途劫走冲击道君的命卷。

### 道枢审计

顶栏「道枢审计」可随时查阅命卷：逐掷记录（TZ-XXXX 编号、缘由与骰值）、哈希链首尾与完整性判定，以及六层防作弊的说明。

## 内容与引擎

- 48 个双选择随机事件（六种核心行动各 8 个）
- 24 件丹药、法器、道材与秘宝；12 名分层敌手
- 12 种结局（六终局 + 六里程碑），机器人可达性测试逐一验证
- 可复现的种子随机数引擎，全程逐掷入册
- 独立的 `daoPattern`、`soulPower`、`territory`、`combat`、`market` 模块
- 每回合资源产出、疆域掌控、寿元与失败结局

核心代码位于 `engine/`：

| 模块 | 职责 |
| --- | --- |
| `creation.ts` | 四步创角门禁、选择顺序与最终选项组装 |
| `daoPattern.ts` | 感悟门槛、凝纹、调和度和纹力 |
| `soulPower.ts` | 神魂消耗、恢复、锤炼和魂战力 |
| `territory.ts` | 开疆难度、占领、失控与资源产出 |
| `combat.ts` | 敌手名录、六式与胜/劫财/夺命/遁四出口 |
| `market.ts` | 法会定价、境界货架与买卖价差 |
| `audit.ts` | SHA-256、逐掷审计、逐令哈希链与回合末不变量 |
| `save.ts` | `SaveEnvelope`（魔数 + 校验和 + 链首）与拒篡改载入 |
| `game.ts` | 创建、六行动循环、事件、物品、结局与里程碑垂问 |
| `content.ts` | 全部事件、物品、结局和创建选项 |
| `testkit.ts` | 机器人驱动，供可达性测试使用 |

## 防作弊六层

存档写在 `localStorage` 键 `daojun_save_v1` 下，外层是一枚 `SaveEnvelope`：魔数、结构版本、状态校验和与审计链首。手改任意数值都会让校验和或链首对不上，载入被拒并提示「道基紊乱，此卷不可续」。

1. **骰子权威** — 一切随机皆经 `recordSpan` 落册，缘由与骰前种子一并入卷
2. **种子确定性** — 种子随卷入档；同种同令，命途逐字节如一
3. **哈希链** — 每道命令 `auditHash = sha256(前链|回合|命令|骰值)`
4. **存档完整性** — 魔数、校验和与链首三者皆需相符
5. **状态不变量** — 命令终了必验，违者整令回溯
6. **单一写者** — 唯 `engine/` 可易天机，界面只递命令

## 测试与静态导出

```bash
npm test
npm run typecheck
npm run build
node scripts/smoke-test.mjs
npm run probe:e2e
```

当前测试集共 265 项，分八个套件：四步创角与回合循环、确定性随机与数据完整性、`daoPattern`/`soulPower`/`territory` 的输入边界、逐掷审计与哈希链、存档信封的拒篡改、六式斗法、法会买卖、里程碑垂问，以及用无头机器人逐一验证十二种结局皆可达的 `reachability.test.ts`。`naming.test.ts` 另行扫描全部源码，防止他作术语（灵石／坊市／天道…）回流。

`probe:e2e` 会验证 `out/index.html`、关键引擎导出、静态包中的唯一存档键、四步创角标记和内容阈值。一键探针会依次执行测试、严格类型检查、干净构建、导出物冒烟检查与该 e2e 探针：

```bash
bash scripts/probe-build.sh
```

Next.js 配置使用 `output: 'export'`。构建完成后可直接托管 `out/`：

```bash
cd out
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
