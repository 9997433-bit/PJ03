# 《道君 · 人生模拟器》

一款纯浏览器文字策略人生模拟器。参悟天地道纹、锤炼神魂、选择剑/法/体/神四条道途，并在修真世界争夺灵地与资源，最终走向十二种不同命数。

## 游玩

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。游戏会自动把存档写入浏览器 `localStorage`，不需要后端服务。

角色创建分为四步：

1. **留名** — 决定名号
2. **问身** — 山村遗孤、世家旁支、江湖散修、破宗余脉
3. **择途** — 剑途、法途、体途、神途
4. **立誓** — 守土、逍遥、问鼎或止戈

进入命卷后可以执行五种核心行动：

- **悟道**：消耗神魂，获得道纹感悟
- **凝纹**：把足够的感悟凝成永久道纹
- **斗法**：以综合战力争夺灵石与声望
- **占地**：消耗粮草与灵气，扩张灵地
- **突破**：满足道纹、神魂和领地要求后渡劫

数字键 `1` 到 `5` 可以快速执行对应行动。乾坤囊中的物品点击即可使用。

## 内容与引擎

- 38 个双选择随机事件
- 24 件丹药、法器、道材与秘宝
- 12 种结局（含四道途专属道君结局）
- 可复现的种子随机数引擎
- 独立的 `daoPattern`、`soulPower`、`territory` 模块
- 每回合资源产出、疆域掌控、寿元与失败结局

核心代码位于 `engine/`：

| 模块 | 职责 |
| --- | --- |
| `daoPattern.ts` | 感悟门槛、凝纹、调和度和纹力 |
| `soulPower.ts` | 神魂消耗、恢复、锤炼和魂战力 |
| `territory.ts` | 开疆难度、占领、失控与资源产出 |
| `game.ts` | 创建、五行动循环、事件、物品和结局 |
| `content.ts` | 全部事件、物品、结局和创建选项 |

## 测试与静态导出

```bash
npm test
npm run typecheck
npm run build
node scripts/smoke-test.mjs
```

一键探针会依次执行测试、严格类型检查、干净构建和导出物冒烟检查：

```bash
bash scripts/probe-build.sh
```

Next.js 配置使用 `output: 'export'`。构建完成后可直接托管 `out/`：

```bash
cd out
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
