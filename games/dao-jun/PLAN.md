## 1. 领域模型(现状 + 整改)

- **道途四择**(创角定,全局分叉):剑/法/体/神——各自道纹池(断岳剑纹…万念神纹)、神魂初值、战力公式权重、专属登顶结局。
- **三轨资源**:
  - **道纹** `DaoPatternState`:感悟 insight(悟道积累)→ 凝纹 engrave(永久,费感悟、耗调和)· 调和 harmony 0–100(凝纹的心境成本,归零危险)· 纹力 patternPower(战力/突破门)。
  - **神魂** `SoulState`:power/maxPower/稳定度 stability——悟道与神通烧魂,炼魂回魂涨稳;稳定度归零 ➕ 触发结局「魂飞魄散」。
  - **领地** `TerritoryState`:灵地 nodes · 掌控 control · 粮草 food · 玄玉(字段 spiritStones,⚠️ 显示名改**玄玉**)· 威望 influence。每回合产出,`claimDifficulty` 随 nodes 递增;失控扣产。
- **境界七阶**(⚠️ G8 整改,按 REALMS 下标改名):观纹 → 铭纹 → 织络 → 凝魂 → 御土 → 合道 → **道君**(victory 门)。突破三重门:道纹数 + 神魂 + 领地要求(现状公式保留)。
- **角色**:age/lifespan、气血、灵气、声望、**因果 karma**(善举积累,喂 benevolent/止戈线)。
- ➕ **道缘**(隐藏属性):创角**藏机暗掷**,永不入 UI 字符串,门控天机级事件(`minDaoYuan`)。

## 2. 创角流程(五步,引擎门禁已有,➕ 两步半)

`creation.ts` 状态机保留(乱序拒绝、中途恢复),扩为:

## 3. 签名机制(本作独有:道纹刻画 + 双轨修行)

### M1 · 道纹刻画(生产系统,已有,补审计)
悟道(烧魂得感悟)→ 凝纹(阈值 `insightNeeded` 递增、调和 ≥20、凝后调和 −8)的**感悟经济**保留;➕ 凝纹时审计掷微调(大成功 +调和,理由「凝纹·断岳」);调和归零后强凝 → ➕ 结局「纹崩道殒」路径。

### M2 · 疆域经营(四作唯一,已有,补失控线)
占地对赌(难度随 nodes 陡增)、每回合产出(粮/玄玉/威望)、失控扣产 保留;➕ 掌控归零且 nodes ≥3 → 强制「疆乱」事件链,处置失败入 ➕ 结局「失土之乱」。领地既是经济也是战力(`territoryPower`)与突破门——**双轨修行:纹魂一轨,山河一轨,偏废哪个都上不去**。

### M3 · 斗法重做(⚠️ G4 收口,`engine/combat.ts` ➕)
一键 `斗法` 升级为**回合制相位**:敌表(`data` 化,≥15 敌)按境界分层;六式:
`力破`(重击,吃体/剑)/ `周旋`(消耗回避,吃身法)/ `布纹`(埋纹阵,下回合引爆)/ `摄神`(魂压,吃神魂,可致敌怯)/ `吞丹`(用丹,不耗攻势)/ `遁土`(借地脉遁走,领地内成功率 +20)。
胜/败/逃三出口;败北分「劫财」(失玄玉/粮)与「夺命」两级;战利品走审计掷;相位锁白名单。战术名与其余三作零重合。
