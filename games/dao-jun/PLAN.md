# 《道君·人生模拟器》实现计划（G3 / `daojun`）

> 原著：萧舒《道君》。基调：**道纹为骨、神魂为本、斗法为锋、道途为命**。天地万物皆
> 蕴道纹，修士以神魂参悟、以斗法印证、以一次次不可回头的道途抉择走向「道君」。
> 玩家扮演**原创角色**，从淬体凡躯起步，在肉身法力与神魂双轨上攀登。

**叙述者：道音**。缥缈简省，像自天地道纹深处传来的回声，惜字如金。
示例语气：「雷落。纹现。你只窥得其一角，已胜过山下十年。」

**技术基线**：同根目录《凡人修仙传》——Next.js 16 静态导出（`output: 'export'` +
`trailingSlash: true`）· TS strict · Tailwind v4 + shadcn/ui · Zustand persist ·
Framer Motion · Vitest。引擎铁律与 `@pj03/engine-core` 契约一致（Round 1/2 vendor 实现）。

---

## 1. 与《凡人》基线的继承与差异

| 维度 | 继承 | 差异（本作特色） |
|---|---|---|
| 回合制 | 1 指令 = 1 回合，回合末 D100 | 新增**悟道事件**：特定地点/天象可 `悟道`，产出道纹感悟 |
| 属性 | 五维+派生 | 双轨进度条：**法力境界** 与 **神魂境界** 相互制约 |
| 战斗 | 骰子回合战 | 分**斗法**（正式挑战、有彩头有规则）与**厮杀**（生死战）两态 |
| 伤害 | 气血 | 新增**神魂创伤**：持久减益，普通静养不可愈 |
| 突破 | D100 对赌 | 三次大境界关口强制**道途抉择**（三选一、不可逆） |
| 商店 | 坊市 | 保留；新增**拓本阁**（道纹拓本交易/交换） |

## 2. 捏人流程（五步）

1. **立名**。
2. **出身（六选一）**：
   | 出身 | 初始加成 | 特点 |
   |---|---|---|
   | 山门杂役 | 心志+2，勤修效率+10% | 低开高走，师门支线 |
   | 世家子弟 | 开局法器+灵石 | 家族斗法义务 |
   | 猎户之子 | 体魄+2，开局「杀纹」感悟 10 | 杀道倾向 |
   | 药庐学徒 | 悟性+2，识药 | 丹道倾向 |
   | 梦中得法 | 神魂+2，开局「梦纹」感悟 10 | 梦道倾向，夜间悟道加成 |
   | 道观扫地童 | 道心+2，开局基础道纹任选其一 | 均衡 |
3. **属性分配** — 20 点五维：体魄 / 悟性 / 道心 / 神魂 / 机变。
4. **本命道纹（D100）** — 从基础纹池抽取本命纹（金/木/水/火/土/风/雷/剑/生/梦 十选一，
   概率不均，剑/梦为稀有），本命纹参悟速度×2 且不可被创伤封印。
5. **暗掷道缘** — 隐藏 D100，影响悟道事件出纹品质；UI 只显示「道音一响，缘法已定」。

## 3. 核心循环

```
修炼(法力)/凝魂(神魂) → 悟道(得道纹感悟) → 刻纹(神魂слот) →
合成神通 → 斗法印证(道名/彩头) → 突破 → 道途抉择 →
探索/主线 → …… → 道君 或 陨落
```

- **双轨制约**：神魂境界决定**刻纹槽数**（2/3/4/6/8）；法力境界决定神通威力系数；
  任一轨落后另一轨两档以上时触发「失衡」减益（心魔/走火事件权重上升）。
- **主线 3 章**：①山门试炼（首个道途抉择前）②群峰论道（斗法圈+第二次抉择）
  ③道君之阶（天地异变，第三次抉择与终局）。

## 4. 进度体系（双轨）

**法力轨**：
| 境界 | 层数 | 寿元 | 关键 |
|---|---|---|---|
| 淬体 | 1–9 | 80 | 自动 |
| 感应 | 1–5 | 110 | 突破 D100 |
| 灵台 | 1–5 | 160 | **开神魂轨**；第一次道途抉择 |
| 道种 | — | 300 | 本命纹入种 |
| 道花 | — | 600 | 第二次道途抉择 |
| 道果 | — | 1200 | 第三次道途抉择 |
| 阳神 | — | 2400 | 神魂合一（需神魂轨 ≥阴神） |
| 道君 | — | — | 结局境界 |

**神魂轨**：魂芽 → 魂湖 → 魂灯 → 阴神 →（与法力轨在阳神合一）。
凝魂消耗回合与法力修炼互斥 —— 资源分配是本作的核心运营题。

## 5. 特色系统（按优先级）

### 5.1 道纹参悟（MUST — 签名系统）
- **基础纹 10 种**（捏人池）+ **衍纹 12 种**（阴/阳/空/时/血/魂/幻/毒/音/光/暗/轮，
  只能由事件与斗法彩头获得）= 22 种，每纹参悟度 0–100。
- 获取途径：`悟道`（在特定节点观雷/观海/观花/观尸骸/入梦，D100+悟性 → 感悟点）、
  拓本阁拓本（一次性 +N）、斗法胜利「印证」（双方共升，胜者多得）。
- 参悟度阈值：30 可刻纹（入战斗）、60 解锁合成、100 圆满（结局条件之一）。

### 5.2 刻纹与神通合成（MUST）
- 神魂槽位有限（见 4），`刻纹` 将道纹刻上神魂（换刻需 1 回合且损失该纹 10 参悟）。
- `合成`：2–3 道纹 → 神通。配方制数据表（≥16 个神通配方），例：
  火+剑=炎阳剑气 · 梦+魂=摄梦术 · 雷+体(土)=霆身 · 生+毒=枯荣手 · 空+剑=遁空斩。
- 未知配方可盲试：D100 大成功发现新配方（入图鉴），大失败神魂创伤 -1 槽 3 回合。
- 神通威力 = f(成分纹参悟度均值, 法力境界系数)；同纹多神通共享参悟成长 —— 构筑感。

### 5.3 斗法台与道名（MUST）
- 周期**论道会**（每 12 回合）+ 随时可 `斗法 <对手>` 挑战名册上的修士。
- 斗法规则：点到即止（败者失彩头与道名，不死）；三败于同一人触发「心障」事件。
- 彩头协商制：拓本/法器/机缘引荐/参悟印证。**道名**（0–100）随胜负涨落，
  是社会性门槛：≥40 解锁上门挑战名宿，≥70 解锁「天下第一」支线，部分结局硬性要求。
- **厮杀**（生死战）只在剧情/仇怨/魔修事件出现：可造成神魂创伤与真死。

### 5.4 道途抉择（MUST — 人生模拟的重开驱动力）
- 三个关口各三选一（灵台：剑道/丹道/梦道 · 道花：杀道/生道/衍道 · 道果：
  独行道/传道/合道），共 27 条组合路径。
- 每次抉择：改变可用神通池、事件表权重、专属支线与结局白名单；**不可逆**，
  UI 用「三炷香」仪式化呈现（选定后另两炷熄灭）。
- 抉择间存在冲突标记（如 杀道×生道 前后选择将触发「道争」内耗事件）——鼓励重开探索。

### 5.5 神魂创伤（SHOULD）
- 厮杀失败/盲试大失败/心障产生创伤条目 `{来源, 减益, 剩余回合|永久}`；
  永久性创伤只能靠稀有丹药/生道神通/特定支线治愈。
- 创伤 ≥3 条时「道心蒙尘」：悟道产出减半 —— 逼迫玩家处理旧伤而非无限莽。

## 6. 指令一览

| 指令 | 效果 | 耗时 |
|---|---|---|
| `修炼` | 法力轨修为 | 1 回合 |
| `凝魂` | 神魂轨修为 | 1 回合 |
| `悟道` | 在当前地点参悟可悟对象（列表制） | 1 回合 |
| `刻纹 <道纹>` | 刻/换神魂槽 | 1 回合 |
| `合成 <纹+纹[+纹]>` | 神通合成（已知配方或盲试） | 1 回合 |
| `斗法 <对手>` / `赴会` | 点到即止的印证之战 / 参加论道会 | 1 回合 |
| `突破` | 境界晋升（关口境界进入道途抉择流程） | 1 回合 |
| `探索` | 当前区域探索 | 1 回合 |
| `静养` | 疗伤（不愈神魂永久创伤） | 1 回合 |
| `坊市` / `拓本阁` | 买卖/换拓 | 1 回合 |
| `使用/装备/赠礼` | 同基线 | 免费 |
| `面板` `背包` `道纹` `神通` `任务` `审计` `保存` | 信息页签（道纹=图鉴+参悟度） | 免费 |
| 战斗中：`神通 <名>` `剑诀` `魂击` `守御` `服药` `遁走` | 斗法/厮杀共用菜单，厮杀额外 `搏命` | — |

## 7. 内容清单（Round 2 验收数量）

- 道纹 22 种（含图鉴文案与相克表：五行环 + 剑克幻、魂克梦、光克暗…）
- 神通配方 ≥ 16 已知 + ≥6 盲试隐藏；法器/丹药/拓本等物品 ≥ 45
- 悟道对象 ≥ 15（雷崖/观海台/古战场/梦泽/花溪…绑定地点 ≥10）

- 随机事件 ≥ 65；主线 3 章；道途专属支线 9 条（每关口选项各 1）
- 27 路径组合各配 1 段专属评语（结局画卷引用）

## 9. 主题与 UI（玄青 × 魂银 × 纹金）

```css
:root[data-game='daojun'] {
  --bg: #0b1418;         /* 玄青黑 */
  --panel: #12222a;
  --ink: #dfe8ea;        /* 霜白 */
  --accent: #3fb6a5;     /* 道纹青（发光元素） */
  --accent-2: #b8c6d4;   /* 魂银（神魂轨/槽位） */
  --gold: #c8a25c;       /* 符金（彩头/道名） */
  --danger: #c14b5a;     /* 血纹红（厮杀/创伤） */
}
```

- 顶栏双境界条（法力青/神魂银）+ 道名徽记。
- **道纹**页签：环形图鉴，参悟度为纹路点亮进度（SVG 描边动画）；刻纹槽以神魂
  剪影上的发光刻痕呈现。
- 道途抉择全屏「三炷香」仪式场景；斗法采用分屏对撞式回合演出。

## 11. 测试计划（≥48 条 Vitest）

- rng/audit/save：重放、哈希链、篡改拒载（8）
- creation：本命纹概率分布（剑/梦稀有权重）、暗掷不外泄（5）
- 双轨：槽数映射、失衡触发/解除、阳神合一前置（7）
- runes/arts：参悟阈值、合成配方命中、盲试大成功/大失败、威力公式边界（10）
- duel：点到即止不致死、道名涨落、三败心障、厮杀创伤（8）
- paths：抉择不可逆、27 组合白名单、冲突标记（6）
- endings：18 结局互斥优先级（隐藏 #2 优先于 #1）（6+）

## 12. 里程碑与范围守卫

- **R2**：引擎+数据+UI 全量、测试 ≥48、`out/index.html` 达标。
- **R3**：QA、平衡（重点：双轨节奏与 27 路径可通率）、zip 发布。
- **MoSCoW**：道纹/刻纹合成/斗法道名/道途抉择 = MUST；神魂创伤 = SHOULD
  （可降级为简单 debuff）；双人斗法/弟子系统 = COULD。
- **红线**：27 条路径组合每条都必须能到达至少 2 个非死亡结局（可达性单测覆盖）；
  盲试合成不得软锁玩家（槽位创伤必须限时恢复）；不抄录原著文本。
