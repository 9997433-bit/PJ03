## 1. 领域模型(既有代码 + 裁定)

- **五维属性**:神魂 shenHun(推演/术法/抗心魔)· 体魄 tiPo(气血/近身)· 悟性 wuXing(修速/习法)· 定力 dingLi(突破稳度/抗劫蚀)· 机变 jiBian(遁走/议价/多一条抉择)。
- **双指针**:气运 fortune 0–100(事件偏移、机缘概率)· **劫运 calamity 0–100**(签名系统:每件好事按 命格×灵根 汇率给它记账;分档 安泰/微澜/阴云/雷动/天诛,触发时从 `data/calamities.ts` 五型劫击 心魔/血光/天雷/业火/天诛 开账单;100 = 天诛)。辅指标:功德 merit(化解货币/结局门)、声望 reputation(宗门阶梯)。
- **命格**(创角 D100 **明掷**,`data/fates.ts` 全覆盖 1..100):天煞孤星/孤鸿命/无格…各带 劫运汇率 calamityRate × 气运汇率 fortuneRate ——决定"好事多贵"。
- **真命**(裁定新增):隐藏属性,创角**匿运暗掷**产生,永不入 UI 字符串;门控天命级事件(`minZhenMing`),满足 SOTA G3 隐藏属性要求。
- **灵根**:金木水火土雷冥 七行,七档(五行杂灵根 … 先天道体),速率 × **劫运亲和**(根越利,天越盯)。
- **境界七阶**(⚠️ 撞名整改,见 ARCHITECTURE §8):**未录**(原"凡尘")→ 引气(9 重)→ **窥命**(原"通玄")→ 玄光 → 元神 → 洞真 → 长生(victory)。突破入境即涨劫运 `calamityOnEntry`——**每一步登高都在给天记账**。
- **功法五路**:道/佛/魔/儒/**图录**(隐藏路线,旗标解锁);`TechniqueNode` 树(父节点前置、三阶、悟性检定习得),路线效果 RouteEffects(修速/劫率/功德每回合/化解加成…)。
- **宗门**:入门费/月例/坊市折扣/声望阶梯;宗门拒收 高劫运 或 低功德 之人。
- **货币显示名**:字段 `stones` 不动,UI 一律显示 **玄晶**(避与根游戏「灵石」撞名)。

## 2. 创角流程(引擎侧步进门禁,5 步)

`creationStep` 状态机,乱序拒绝;中途刷新可恢复;完成前锁 playing。

1. **报名**:姓名(司命翻开簿册:「查无此人。补录。」)。
2. **问身**:六出身(`data/origins.ts`:各带起始 玄晶/气运/劫运/功德/旗标 与机读 special)。
3. **定数**:**30 点**分配五维(守恒断言)。
4. **观根**:D100 审计掷定灵根(表覆盖 1..100)——司命当场念出劫运亲和,明明白白告诉你代价。
5. **排盘**:D100 明掷定命格(fates 表)+ **匿运暗掷**定真命(审计只见"掷过")。落子无悔。

## 3. 签名机制(全要,本作独有)

### M1 · 劫运账簿与命盘(核心差异化,`engine/calamity.ts` + 命盘页签)
- 劫运是**表**不是事件:被动积累(修行/机缘/突破 × 命格汇率 × 灵根亲和),档位越高、每回合劫击判定越凶。命盘页签实时显示:当前档位、账目明细(近 10 笔劫运来源)、**推演可见的未来劫击预报**(见 M2)。
- 劫击落地走 `data/calamities.ts`:心魔(清明)/血光(气血伤势)/天雷(修为,高阶须战)/业火(玄晶气运声望)/天诛(一切)。劫后 `vent` 放电降表——**硬抗是便宜的降法,化解是贵但不疼的降法**。
- 化解五式(`MitigationDef`,已有数据):散功德/舍财/隐匿/布阵/应劫,各带成本、成功率与降量;成败入审计。

### M2 · 推演(生产系统换皮,`engine/divination.ts` + `techniques.ts`)
- **卜算**(耗神魂 + 玄晶):向前推演 N 回合劫击预报,写入命盘(种子化——预报即承诺,到期必应,测试锁死)。
- **推演功法**:沿 `TechniqueNode` 树消耗 静室回合 + 残页/玄晶,悟性检定习得或升品;失败累积「推演心得」pity(保底,照根游戏突破 pity 模式);大成功产出**本命化**版(专属加成)。图录路线由「图录残页」旗标链解锁。

### M3 · 匿运与改命(玩法反转,`engine/fateOps.ts`)
- **匿运**(开关态自由指令):每回合烧玄晶维持;期间 事件掷气运偏移归零、劫运**冻结不再累积**、修为收益 −20%——"天机看不见你,机缘也找不到你"。开/关各入审计;匿运回合计数入 stats(喂结局 无录之人)。
- **改命**(高消耗指令):对命盘上指定劫击发起 D100 对赌(气运加成):成功 → 转嫁/延期/降级(审计理由「改命·转嫁」等);失败 → 劫升一级且 改命反噬计数 +1。反噬 ≥3 触发专属结局。无论成败,**原劫记录保留于审计**——被抹除的命运可回看(继承 R1-F1 稿创意)。

## 4. 回合循环与指令表

`turn.ts` 管线同根骨架;回合末新增**劫运结算段**:被动累积 → 档位判定 → 劫击掷(档位越高概率越大)→ 强制 pending(战斗型进 combat 相位)。不变量:气运/劫运 0–100、玄晶非负、功德可负但有下界,违者整回合回滚。

| 指令 | 效果 | 耗时 |
|---|---|---|
| `修行` | 修为 = base × 灵根 × 功法 × 伤势;劫运照汇率记账 | 1 回合 |
| `突破` | D100 对赌进下一境;成则劫运+`calamityOnEntry` | 1 回合 |
| `历练` | 探访遗迹/接宗门任务,遇敌与机缘 | 1 回合 |
| `推演 [功法]` | M2 功法树习得/升品 | 1 回合 |
| `卜算` | 预报未来劫击入命盘 | 1 回合 |
| `化解 [式]` | 散功德/舍财/布阵/应劫(隐匿=匿运开关) | 视式而定 |
| `改命 [劫]` | 对指定劫击 D100 对赌(M3) | 1 回合 |
| `匿运` | 开/关遮蔽(免费切换,烧玄晶按回合) | 免费 |
| `静修` | 疗伤、回气血法力 | 1 回合 |
| `万法坊` / `买/卖` | 市集(境界分层货架,宗门折扣) | 进入 1 回合 |
| `拜山 [宗门]` | 求入宗门(劫运/功德门槛) | 1 回合 |
| `使用/装备/赠礼` | 用丹、佩器、结好 | 免费 |
| `命盘/行囊/宗门/审计/保存` | 免费查看 | 免费 |
| 斗法中:`雷法/卦步/布阵/神通/服丹/遁空` | 回合制布阵斗法 | — |

快捷键:平时 `1` 修行 `2` 突破 `3` 历练 `4` 卜算;`5–9` 切页签(命盘/万法坊/行囊/宗门/审计)。斗法 `1–6` 六式;事件抉择 `1–9`。

**斗法**(战斗换皮):敌方带**命数克制**标签(与玩家当前劫属性生克,伤害 ±15%);胜/败/逃三出口,败北分「劫财」(业火型)与「夺命」两级;布阵成功埋伏击 buff,卦步赚闪避,遁空检定吃机变。战斗相位锁白名单。
