# 《灭运图录·人生模拟器》实现计划（G2 / `mieyun`）

> 原著：爱潜水的乌贼《灭运图录》。基调：**理性修仙 × 命运博弈**——天机可测、劫数
> 轮转、根基决定上限、每一步选择都在命盘上留下轨迹。玩家扮演**原创角色**，生于
> 大劫将起的时代，命轨早已写定；或应劫而亡，或步步为营，最终**灭去自身命运**。

**叙述者：天机**。声音精确冷静，像一台推演命运的仪器，偶露悲悯。
示例语气：「推演终了。此路生机三成七，劫气增二。落子与否，在你。」

**技术基线**：同根目录《凡人修仙传》——Next.js 16 静态导出（`output: 'export'` +
`trailingSlash: true`）· TS strict · Tailwind v4 + shadcn/ui · Zustand persist ·
Framer Motion · Vitest。引擎铁律与 `@pj03/engine-core` 契约一致（Round 1/2 vendor 实现）。

## 1. 与《凡人》基线的继承与差异

| 维度 | 继承 | 差异（本作特色） |
|---|---|---|
| 回合制 | 1 指令 = 1 回合，回合末 D100 | 叠加**纪元时钟**：每 20 回合一小劫、60 回合一大劫 |
| 突破 | D100 对赌 | 突破前置**资粮积累**，决定道基/金丹品级（品级封顶后续境界） |
| 事件 | 境界加权事件表 | 事件表额外受 **气运/劫气** 双值加权；命轨事件为**定数**（必然触发） |
| 商店 | 坊市 | 保留；新增**残篇黑市**（功法残页交易，推演系统的输入） |
| 战斗 | 骰子回合战 | 新增 `夺运` 战术（对气运之子）与 `布阵` 前置回合 |
| 存档 | 校验和信封 | 新增命轨快照：`改命` 后旧轨迹保留于审计（可回看被抹除的命运） |

## 2. 捏人流程（五步）

1. **立名**。
2. **出身（六选一）**：
   | 出身 | 初始加成 | 隐患 |
   |---|---|---|
   | 大宗外门弟子 | 功法入门+资源渠道 | 宗门任务义务（周期事件） |
   | 散修遗孤 | 自由+黑市门路 | 无靠山，劫掠事件权重高 |
   | 世家旁支 | 灵石丰厚+人脉 | 家族气运绑定（家族劫连坐） |
   | 药园杂役 | 药理知识+丹材折扣 | 起点境界低半档 |
   | 猎妖人后裔 | 战斗天赋+妖类情报 | 开局背负血仇命轨 1 条 |
   | 天生道体 | 修炼速度×1.3 | 「怀璧」命轨：夺运者觊觎 |
3. **属性分配** — 20 点五维：根骨 / 悟性 / 心性 / 神识 / 气运。
4. **命格抽取（D100 天命签）** — 决定显性命格（紫微入命/福星高照/平庸之命/
   七杀照命/天煞孤星/劫运缠身…共 10 档，好坏皆有补偿设计：凶格附赠高倍机缘权重）。
5. **命轨织定（暗掷）** — 引擎按出身+命格生成 **3–5 条命轨**（预定事件，含触发回合窗
   与吉凶），仅显示条数与「天机朦胧」的模糊谶语；具体内容需游戏内 `天机` 推算解锁。

## 3. 核心循环

```
修炼/推演/历练 → 资粮与感悟积累 → 突破（品级结算）→
气运/劫气变动 → 纪元时钟推进 → 小劫/大劫/命轨事件 →
天机推算 → 改命/应劫/避劫 → …… → 灭运 或 应劫而亡
```

- **纪元时钟**是第二条进度轴：顶栏常驻显示「距下一劫 N 回合」，玩家所有规划围绕
  劫期展开（劫前苟住 or 劫中夺机缘）。
- **主线 3 章**：①末法先兆（入门与第一次小劫）②气运之争（宗门卷入大劫）
  ③灭运之路（图录线索集齐，终局抉择）。

## 4. 进度体系（单道深挖：道基品级是命门）

| 境界 | 层数 | 寿元 | 关键规则 |
|---|---|---|---|
| 练气 | 1–9 | 90 | 自动升层 |
| 通脉 | 1–5 | 120 | 需突破；脉数=资粮档 |
| 凝煞 | 1–3 | 160 | 煞气纯度（1–100）入道基公式 |
| **道基** | 九品~一品 | 300 | **品级 = f(功法品阶, 煞气纯度, 资粮, D100)**；七品以下止步金丹 |
| 金丹 | 三转~九转 | 600 | 转数受道基品级封顶 |
| 元神 | — | 1200 | 需渡雷劫（大劫期间渡劫难度×1.5） |
| 返虚 | — | 2500 | 天人五衰开始倒计时 |
| 合道 | — | — | 结局境界 |

「**一步慢，步步慢**」：低品道基可通过稀有事件「洗基重铸」补救一次（代价：跌落一境
+劫气+20）。这是理性流核心张力——抢时间 vs 磨根基。

## 5. 特色系统（按优先级）

### 5.1 气运/劫气双值 + 纪元劫数（MUST — 签名系统）
- **气运**（0–100，显示）：加权全部吉事件；>80 触发「木秀于林」被觊觎事件。
- **劫气**（0–100，显示）：杀戮、夺宝、毁诺、夺运积累；决定劫中事件烈度
  `severity = base(劫种) × (1 + 劫气/50)`。
- **小劫**（每 20 回合）：从 天灾/兵祸/心魔/仇杀 中按状态加权抽取，2–3 回合事件链。
- **大劫**（每 60 回合）：全地图级章节事件；渡过者气运 +15，道基品级判定 +1 档机会。
- 功德行为（护城/赠药/传法）消劫气；「闭死关」可跳过小劫但停滞成长且劫气不减。

### 5.2 命轨与改命（MUST — 签名系统）
- 命轨 = `{谶语, 触发窗口[t1,t2], 事件id, 吉凶, 可改写性}`；到窗必发，无视概率 —— 与
  随机事件形成「定数 vs 变数」双轨。
- `天机` 指令：消耗神识+灵石，D100 揭示一条命轨详情；每次使用累积**天机反噬**值
  （>60 开始掷心魔判定）。
- `改命`：终盘能力。条件 = 集齐图录残页 ≥N + 气运 ≥60；效果 = 抹除/改写一条命轨，
  代价 = 气运 -30、劫气 +15、天机反噬 +20。被抹除的命轨进入审计页「灰轨」区。
- **灭运**（隐藏终局）：改写包含「己身死亡」在内的全部命轨后解锁终局仪式章节。

### 5.3 推演系统（MUST — 理性修仙的手感来源）
- 输入：功法残页（黑市/探索/劫中掉落，带品阶与残缺度）。
- `推演 <残页组合>`：耗 1 回合，成功率 = f(悟性, 残页契合度, D100)；成功合成更高阶
  功法或神通；大失败产生「悟障」（修炼效率 -20%，需静养/丹药清除）。
- 功法品阶直接进道基品级公式 —— 推演是根基流的核心投资。

### 5.4 夺运（SHOULD — 高风险战术）
- 战斗中对「气运之子」标记的敌人可选 `夺运`：胜则转移其气运的 50%，但劫气 +25 且
  生成一条新的仇杀命轨（其师门/护道人）。
- 平衡阀：全周目夺运收益上限 3 次，超过后每次额外 -10 心性（心魔权重上升）。

### 5.5 护道盟约（COULD）
- 与 NPC 缔结双向盟约：大劫中双方各获一次「代承伤害」；若盟友身死，玩家得
  「护道遗泽」buff 与一条愧疚心魔线。养 NPC 情感线的理性流表达。

## 6. 指令一览

| 指令 | 效果 | 耗时 |
|---|---|---|
| `修炼` | 增长修为与资粮 | 1 回合 |
| `推演 <残页…>` | 合成/升阶功法（D100） | 1 回合 |
| `突破` | 晋升（含道基/金丹品级结算） | 1 回合 |
| `历练` | 外出探索（地点+劫期加权） | 1 回合 |
| `天机` | 推算一条命轨详情（反噬累积） | 1 回合 |
| `改命 <命轨>` | 抹除/改写命轨（终盘） | 1 回合 |
| `闭关` | 连续修炼 3 回合（期间事件跳过，劫期不可用） | 3 回合 |
| `静养` | 疗伤/清悟障 | 1 回合 |
| `坊市` / `黑市` | 买卖（黑市含残页与禁物） | 1 回合 |
| `结盟 <NPC>` | 缔结护道盟约 | 免费 |
| `使用/装备/赠礼` | 同基线 | 免费 |
| `面板` `背包` `命盘` `功德` `任务` `审计` `保存` | 信息页签 | 免费 |
| 战斗中：`强攻` `游斗` `布阵` `神通` `夺运` `服药` `遁走` | 回合战 | — |

## 7. 内容清单（Round 2 验收数量）

- 随机事件 ≥ 70（含劫种事件链 4 类 × 3 烈度）；命轨事件池 ≥ 25
- 功法 ≥ 20（凡/黄/玄/地/天五阶）+ 残页 ≥ 40；神通 ≥ 12
- 地点 ≥ 10（宗门/坊市/黑市/秘境/劫区）；NPC ≥ 12（气运之子 ≥3、可结盟 ≥5）
- 物品 ≥ 45；丹方 ≥ 8（清悟障/压心魔/续命类为特色）
- 命格 10 档 × 谶语文案；谶语模板 ≥ 30 条

## 9. 主题与 UI（玄紫夜空 × 星轨命金 × 劫红）

```css
:root[data-game='mieyun'] {
  --bg: #120f1d;         /* 玄紫黑 */
  --panel: #1a1530;
  --ink: #e4e0f0;        /* 月白 */
  --accent: #d4af5f;     /* 命金（气运/星轨） */
  --accent-2: #8d7bd8;   /* 星紫（天机/推演） */
  --danger: #d04848;     /* 劫红（劫气/大劫） */
  --success: #5fae8f;    /* 功德青 */
}
```

- 顶栏新增双条：气运（金）/劫气（红）+ 纪元时钟倒计时圆环。
- **命盘**页签：星盘放射图，命轨为环上刻痕（未解锁=雾纹，已改写=灰轨划痕）。
- 大劫开场用全屏星幕暗转动画（Framer Motion）；谶语用竖排排版呈现。

## 11. 测试计划（≥48 条 Vitest）

- rng/audit/save：重放、哈希链、灰轨快照保留（8）
- creation：命格 10 档分布、命轨生成数量与窗口合法性（6）
- epoch：20/60 节拍、闭死关跳劫规则、劫烈度公式（7）
- fate：命轨必发性（窗口内无视概率）、天机反噬阈值、改命前置与代价、灭运解锁（10）
- grade：品级公式边界（七品封顶金丹、洗基一次性）（6）
- derive：契合度成功率、大失败悟障、品阶继承（5）
- combat/夺运：收益上限 3 次、仇杀命轨生成（4）
- endings：18 结局互斥优先级（含 #4 讽刺结局优先于 #2）（6+）

## 12. 里程碑与范围守卫

- **R2**：引擎+数据+UI 全量、测试 ≥48、`out/index.html` 达标。
- **R3**：QA、数值平衡（重点：劫烈度曲线与道基品级分布）、zip 发布。
- **MoSCoW**：双值+纪元劫数/命轨改命/推演 = MUST；夺运 = SHOULD；护道盟约 = COULD。
- **红线**：命轨「必发」不得被随机事件挤掉（调度器优先级测试保证）；
  天机反噬永不直接杀死玩家（只走疯癫结局路径）；不抄录原著文本。
