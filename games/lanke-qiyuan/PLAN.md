- 技术形态与根游戏一致:Next.js 静态导出、zustand+persist、种子化审计骰、单一回合解析器(见 ARCHITECTURE §4 铁律)。

## 1. 领域模型(既有代码,摘要)

- **五心属性**:心境 xinJing(抗心尘、坐忘深度)· 悟性 wuXing(修行速度)· 才学 caiXue(读谱、与鬼神论道)· 气韵 qiYun(精怪缘分)· **缘法 yuanFa(隐藏,覆枰暗掷,永不入 UI 字符串,门控奇遇事件)**。
- **三表一钱**:心神 spirit(0 不致死,归零强制坐忘)· 心尘 dust 0–100(高尘封锁突破、事件变酸)· 棋道 chessDao 0–100(全游戏主线刻度)· 悟 insight(观棋/弈道赚取,用于悟谱)· 银钱 coin。
- **七境**(每境 初境/中境/圆融 三段):凡尘 → 明心 → 养气 → 通玄 → 坐忘 → 逍遥 → 天人。突破双门:修为够 + `chessDaoGate`(棋道门槛)+ 心尘低于 `dustCeiling`——**光肝修为上不去,必须下棋、必须心净**。
- **棋缘**(灵根等价物,创角 D100 一次定):顽石之缘 0.6× … 太虚棋缘 3.0×,附 松/竹/云/水/石/月/风 灵机与弈道加成。
- **精怪录**:山精/鬼魅/器灵/水族/狐仙/神祇 ≥8 位,好感 −50…100,阈值解锁赠礼/传谱/结局线。
- **心境状态 Mood**:boon/burden 双类,影响修速/弈道/突破/每回合心神心尘。

## 2. 创角流程(引擎侧步进门禁,≥4 步)

`creationStep: 0→4` 状态机,乱序调用被拒(非 UI 约束);中途刷新可恢复;完成前无法进入 playing。

1. **立名**:姓名 + 道号(courtesy,精怪称呼你用道号)。
2. **问身**:六出身卡(落第书生/棋馆学徒/疏财商贾/山客/画师/游方郎中——已在 `data/origins.ts`,各带机读 perk:笔生/听子/静者/博览/疏财/行脚),影响起始钱、物品、棋谱、棋道。
3. **定心**:**28 点**分配到四项可见属性(点数守恒,引擎断言;缘法不可分配)。
4. **落子问缘**:D100 审计掷定棋缘(七档表全覆盖 1..100);随后**覆枰暗掷**产生缘法(审计只见"掷过",永不见值)。落子无悔,两掷均入审计链。

## 3. 签名机制(三件全要,本作独有)

### M1 · 棋盘天机(核心差异化,`engine/board.ts` + 独立页签)
- 全局一张 **9×9 命理棋局**(替代根游戏"炼丹"页签位)。善缘事件/授业得 **白子**,取巧抉择/欠因果得 **黑子**(计数资源,不占行囊)。
- 指令 `落子`(耗 1 回合):选星位落白子 → 未来 N 回合事件掷向吉桶偏移或解锁指定精怪线;落黑子 → 立取大利(银钱/修为)但埋 `劫` 旗标,喂给后续讨债事件链。落点精度受**棋品**门控(见 M4),微偏由审计掷决定(理由如「落子·天元」)。
- 盘面入存档、入哈希链;偏移量有界(不变量断言,防滚雪球)。

### M2 · 烂柯观弈(时间跳跃,`engine/lanke.ts`)
- 稀有奇遇「山中观弈」(奇遇桶,缘法门):选择看完一局 → 审计掷**一次跳过 4–12 回合**,棋道大涨、寿元照扣、世界照常结算(好感衰减、Mood 到期、任务超时)。"一局烂柯,人间数载"。
- 若跳跃吞没剩余寿元 → 直接进结局 `end_lanke`(烂柯,天级)——死得其所。

### M3 · 弈道对局(冲突系统,战斗换皮,已有类型)
- 无血量,打 **目数 margin**:对手 `OpponentDef`(strength/hands/counters/weakTo),逐手过招。五棋风:`稳守 / 急攻 / 弃子(牺牲一件物品换先机) / 试探(赚先手) / 封盘(和棋离场)`,外加 `投子`。含先手 initiative 与劫争 ko(下一手翻倍)双状态。
- 胜/负/和/投子四出口,均不致死;输的是银钱赌注与心神。战斗相位锁:对局中非对局指令被拒。

### M4 · 棋品九段(进度侧轨,派生量)
- 由 弈道胜局 + 观棋数 + 棋道 折算段位(初段…九段);段位门控 M1 可落星位(低段只许边角,九段可落**天元**)与高阶对手解锁。存档只存原始计数,段位纯派生(单一事实源)。

## 4. 回合循环与指令表

`turn.ts` 管线照根游戏骨架:clone → 相位守卫 → dispatch → 时间推进 → 回合事件掷(D100+缘法偏移+盘面偏移 → 四桶)→ 精怪/任务扫描 → 哈希链 → 不变量(心尘 0–100、银钱非负、棋道 0–100,违者整回合回滚)。

| 指令 | 效果 | 耗时 |
|---|---|---|
| `修行` | 打坐养气,修为 = base × 棋缘 × 谱 × Mood | 1 回合 |
| `破境` | 冲击下一境(D100,双门:棋道 + 心尘) | 1 回合 |
| `游历 [地名]` | 舆图移动 + 地缘事件掷 | 1 回合 |
| `观棋` | 观人对弈,得悟与棋道(听子 perk +50%) | 1 回合 |
| `弈道 [对手]` | 摆枰开局(进入 match 相位) | 1 回合 |
| `落子` | 棋盘天机落白/黑子(M1) | 1 回合 |
| `坐忘` | 回心神、扫心尘(清 burden 类 Mood) | 1 回合 |
| `授业` | 教棋,得银钱 + 白子 | 1 回合 |
| `墟市` / `买/卖` | 集市交易(**不叫"坊市"**,避与根游戏撞名) | 进入 1 回合,买卖免费 |
| `参谱/悟谱 [谱名]` | 研读/以悟解锁棋谱 | 参谱 1 回合,悟谱免费 |
| `使用/赠礼` | 用物、赠精怪结缘 | 免费 |
| `面板/行囊/精怪录/天机/审计/保存` | 免费查看(天机=棋盘视图) | 免费 |
| 对局中:`稳守/急攻/弃子/试探/封盘/投子` | 逐手过招 | — |

快捷键:平时 `1` 修行 `2` 破境 `3` 游历 `4` 观棋;`5–9` 切页签(天机/墟市/行囊/精怪录/审计)。对局中 `1–6` 对应六式;事件抉择 `1–9` 直选。输入框聚焦时让位。

## 5. 事件系统(≥40)

四桶:`波折 / 寻常 / 际遇 / 奇遇`(温和世界无"大凶"桶,凶事收敛于波折——与 SOTA G5 五桶等价换皮,dataIntegrity 按四桶断言)。D100 定桶(受缘法 + 盘面偏移),桶内加权抽取,两掷均入审计。

- 内容族:市井温情(灯会/赠伞/义诊)、鬼狐奇谭(狐求字/鬼托梦/器灵认主)、棋事(茶楼赌棋/盲棋老者/复盘残局)、波折(山魈/水匪/讼事)。
- ≥30% 带抉择(D20+属性 vs DC,成败双效果);`minYuanFa`(隐藏门)/`minChessDao`/`requiresFlag`/`once` 齐备。
- ≥5 条旗标链:**烂柯洞**链(通往 M2 与 end_lanke)、**狐仙报恩**链、**书生赶考**链、**无字谱**链(通往 end_wuzi)、**黑子讨债**链(M1 埋劫)。
- 每桶 × 每境界段至少 1 个可命中事件,dataIntegrity 锁死。

## 8. 测试计划(≥40,签名机制 ≥5)

1. rng 确定性 23 项(照搬根游戏)+ 覆枰封印断言。
2. 创角门:步进不可跳、28 点守恒、棋缘表覆盖 1..100、缘法永不入 UI 串。

4. 回合解析器:时间推进、pending 锁、match 相位锁、不变量回滚。
5. 审计:哈希链、许愿拒绝、同种子同指令逐字节回放。
6. dataIntegrity:悬空 id、四桶×七境覆盖、**16 结局全可达**、结局判定序。
7. 签名专项 ≥5:落子偏移有界+入审计、黑子劫链埋旗、烂柯跳跃后 年龄/寿元/Mood/任务 一致性、棋品门控落子位、弃子消耗物品。
