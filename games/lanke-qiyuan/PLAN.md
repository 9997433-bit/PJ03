# 《烂柯棋缘·人生模拟器》实现计划（G1 / `lanke`）

> 原著：真费烟《烂柯棋缘》。基调：**温和治愈的人间修行**——志怪、烟火气、君子之交、
> 因果有报。玩家扮演**原创角色**，一缕生魂落入这个仙、文、武、妖、鬼神五道并行的
> 世界，以游历为骨、以缘分为脉、以一局天地棋为魂，走完自己的一生。

**叙述者：弈者**。声音温和克制，带一点旁观棋局的悠然，与《凡人》冷峻的天道形成对照。
示例语气：「你落下此子时，江上正起晚风。棋势缓了半分，人心却热了三分。」

**技术基线**（与根目录《凡人修仙传》完全一致，不再赘述细节）：
Next.js 16 App Router + `output: 'export'` + `trailingSlash: true` · TypeScript strict ·
Tailwind v4 + shadcn/ui · Zustand persist · Framer Motion · Vitest。
引擎铁律：纯函数引擎（零 React）、种子化骰子单点权柄、九层防作弊、
校验和存档信封 —— 接口签名以 `@pj03/engine-core` 契约为准，Round 1/2 vendor 实现。

## 1. 与《凡人》基线的继承与差异

| 维度 | 继承 | 差异（本作特色） |
|---|---|---|
| 回合制 | 1 指令 = 1 回合（约 3 个月），回合末 D100 定吉凶 | 事件表按**当前地点**加权，而非仅按境界 |
| 引擎结构 | engine/data/store/components 四层 | 新增 `board.ts`（命星棋盘）`karma.ts`（因果账本）`journey.ts`（游历） |
| 死亡 | 存在真死 | **温和死亡曲线**：气血归零先掷「护身缘」D100（因果善缘可挡一次死劫），寿终结局占比高 |
| 进度 | 单一修仙境界 | **三主道并行**（仙/文/妖）+ 神道敕封（结局分支）+ 武道（凡俗技能线） |
| 商店/炼丹 | 坊市+炼丹 | 坊市保留；炼丹替换为**酿酒/篆符**二选一生活技艺（轻量） |

## 2. 捏人流程（五步，落子无悔）

1. **立名** — 输入姓名（或掷骰取名池）。
2. **出身（六选一）** — 决定初始道途倾向、属性加成、初始地点：
   | 出身 | 倾向 | 初始加成 | 起点 |
   |---|---|---|---|
   | 樵门遗孤 | 仙 | 体魄+2，隐藏「烂柯缘」标记 | 烂柯山下村 |
   | 寒门书生 | 文 | 悟性+2，文运+10 | 宁水县 |
   | 云游道童 | 仙 | 道心+2，开局符箓×2 | 山中道观 |
   | 狐山小妖 | 妖 | 灵性+2，可化形前只能夜间入城 | 狐山 |
   | 江湖武人 | 武 | 力道+2，开局刀法一式 | 州府镖局 |
   | 水乡渔家子 | 妖/仙 | 气运+1，隐藏「江龙缘」标记 | 通天江畔 |
3. **属性分配** — 20 点分配至 五维：体魄 / 悟性 / 道心 / 灵性 / 气运（各 1–10）。
4. **命星初落（D100）** — 抽取**本命星位**（决定命星棋盘上己方星位吉凶与初始棋缘容量 3–7）。
5. **暗掷机缘** — 隐藏 D100（永不显示数值），影响奇遇权重；UI 只显示「弈者已暗落一子」。

## 3. 核心循环

```
游历（选择路线）→ 抵达节点 → 本地事件/志怪小story（2–4回合）→
修行/读书/手谈/助人 → 缘分与因果累积 → 命星棋盘落子 →
突破/科举/化形 → 大事件（章节）→ …… → 结局
```

- **游历为骨**：世界是「州府—县城—山野—江河—古刹」节点图（≥12 节点）。`游历` 指令
  沿边移动（1 回合），途中掷「路遇」D100。城镇提供坊市/客栈/书院；山野提供修行/奇遇。
- **章节主线**（3 章）：①宁水县鬼祸（入世）②通天江龙宴（结缘）③黑荒妖乱（抉择）。
  每章 3 个抉择节点，抉择影响因果与可用结局。

## 4. 进度体系（三主道，可兼修但共享寿元与回合）

**仙道**（樵/道/渔起手顺滑）：
| 境界 | 层数 | 寿元 | 备注 |
|---|---|---|---|
| 凡身 | — | 80 | 起点 |
| 引气 | 1–9 | 100 | 自动升层 |
| 定神 | 1–5 | 150 | 需突破（D100） |
| 洞明 | 1–5 | 250 | 需突破，开「望气」被动 |
| 结丹 | — | 500 | 需突破+丹引 |
| 阳神 | — | 1000 | 需突破+雷劫 |
| 乘云 | — | — | 结局境界（飞升） |

**文道**（书生起手）：开蒙 → 童生 → 秀才 → 举人 → 进士 → 翰林 → **文华贯顶**。
以「文运」值+科举事件（三年一考，D100+悟性+文运修正）推进；高文运可「言出法随」
（战斗中正气伤害对鬼邪翻倍）。

**妖道**（狐山/渔起手）：开智 → 通灵 → **化形**（关键 D100，失败留兽相破绽）→
妖丹 → 大妖 → 登仙/化龙。妖修入城有「显形」风险事件；行善积德可消除猎妖人敌意。

**武道**（凡俗技能线，任何出身可练）：炼皮 → 炼骨 → 易筋 → 洗髓 → 罡气。
只加战斗力与体魄上限，不给寿元 —— 保底可玩性与「江湖武圣」结局入口。

## 5. 特色系统（本作卖点，按优先级）

### 5.1 命星棋盘（MUST — 签名系统）
- 抽象为 **9 星位 + 天元** 的小棋盘（非 19 路全盘，控制范围）。
- 与 NPC 缘分 ≥ 60 时可将其「请入棋局」成为**星位棋子**（上限=初始棋缘容量，可成长）。
- 每颗棋子提供一条**被动命势**（如：城隍棋子 → 鬼祸事件伤害 -30%；老龙棋子 → 江河
  节点奇遇权重 +15）。
- 每章一次**落子**主动权：消耗该棋子本章行动，强制改写一次事件判定（把一次 D100
  重掷并取优）。落子后该 NPC 的支线推进。
- 引擎实现：`board.ts` 输出「事件表权重修正向量」，`events.ts` 合成时应用；可单测。

### 5.2 因果账本（MUST）
- 每次助人/害人记录 `{对象, 类型, 分量, 回合}`；善缘/恶业分账。
- 成熟机制：善缘条目在 8–20 回合后按 D20 触发**回响事件**（报恩/引荐/托梦）；
  恶业触发寻仇/官府/猎妖人。
- 善缘总量兑换「护身缘」：气血归零时自动掷 D100 ≤ 善缘/2 则免死一次（每周目至多 2 次）。

### 5.3 手谈（SHOULD — 骰子棋局小游戏）
- 与可对弈 NPC `手谈`：三轮比试，每轮双方 D20 + 棋力修正，两胜制。
- 每轮玩家先选**棋风**：布局（+2 防守，输时少失彩头）/ 攻杀（+0，赢时彩头×1.5）/
  治孤（落后时 +4，领先时 -2）。
- 彩头：情报、缘分 +15、传承残页、灵石。输棋只失彩头不伤身 —— 符合温和基调。

### 5.4 生活技艺：酿酒/篆符（COULD）
- 二选一入门；酿酒产出「赠礼特化」道具（缘分收益×2）；篆符产出一次性战斗/避劫符。
- 复用《凡人》炼丹的「配方+D100 成败」骨架，内容量减半。

## 6. 指令一览

| 指令 | 效果 | 耗时 |
|---|---|---|
| `修行` | 当前主道打坐/读书/吐纳（按道途自动映射） | 1 回合 |
| `游历 <地点>` | 沿节点图移动，途中路遇判定 | 1 回合 |
| `探访` | 探索当前节点的志怪线索 | 1 回合 |
| `突破` / `赴考` / `化形` | 三道各自的关键晋升（D100） | 1 回合 |
| `手谈 <NPC>` | 对弈小游戏 | 1 回合 |
| `落子 <棋子>` | 激活星位棋子改写判定（每章一次） | 免费 |
| `静养` | 疗伤回血 | 1 回合 |
| `坊市` | 城镇内买卖 | 1 回合 |
| `酿酒` / `篆符` | 生活技艺开炉 | 1 回合 |
| `赠礼 <NPC>` / `使用 <物品>` / `装备 <物品>` | 结缘/消耗/穿戴 | 免费 |
| `面板` `背包` `棋盘` `因果` `任务` `审计` `保存` | 信息页签 | 免费 |
| 战斗中：`强攻` `游斗` `剑意` `符箓` `服药` `遁走` | 回合制搏杀 | — |

快捷键沿用《凡人》方案：`1–3` 高频行动、`4–9` 页签、战斗 `1–6`、抉择 `1–9`。

## 7. 内容清单（Round 2 验收数量）

- 事件表 ≥ 70 条（按节点类型 × 境界档加权，含 ≥10 条志怪小 story 多回合链）
- 节点 ≥ 12、NPC ≥ 14（其中可对弈 ≥6、可入棋盘 ≥8；含致敬位：青衫先生/白毛狐儿/江中老龙，不直呼原著名讳全名以外的私设剧情）
- 物品 ≥ 45（酒、符、棋谱、文房、法器、妖丹材料）
- 主线 3 章 × 3 抉择节点；支线 ≥ 8（NPC 棋子支线优先）
- 名池：人名/斋号/酒名/棋谱名各 ≥ 20

## 10. 项目结构（相对 `games/lanke-qiyuan/`）

```
src/
├── app/            # / 标题页 · /game 主屏（同《凡人》两路由模式）
├── engine/         # types rng audit save creation attributes turn commands
│   ├── journey.ts  #   节点图与游历
│   ├── board.ts    #   命星棋盘（权重修正向量）
│   ├── karma.ts    #   因果账本与回响
│   ├── chess.ts    #   手谈判定
│   ├── paths.ts    #   仙/文/妖/武 四线进度
│   └── …           #   combat events economy inventory npc quests lifecycle narrative
├── data/           # nodes npcs events items endings names chapters recipes(酒/符)
├── store/gameStore.ts
└── components/     # ui/ + game/（BoardView KarmaView ChessDuel JourneyMap …）
```

配置：`next.config.mjs` 抄根游戏（export + trailingSlash + unoptimized）；
`package.json` 脚本必须含 `dev` `build` `test` `typecheck`（供根编排脚本调用）。

## 11. 测试计划（≥45 条 Vitest）

- rng/audit/save：种子重放、哈希链、篡改拒载（8）
- creation：六出身模板、属性守恒、暗掷不外泄（6）
- journey/board/karma：节点连通、棋子容量上限、权重修正合成、回响成熟窗口、
  护身缘至多 2 次（12）
- paths：三道晋升条件、科举周期、化形失败破绽（8）
- chess：三轮两胜、棋风修正、彩头结算（5）
- endings：18 结局判定互斥优先级表（6+）

## 12. 里程碑与范围守卫

- **R1（已完成部分）**：本 PLAN + 脚手架。
- **R2**：引擎全量 + 数据全量 + UI 全量 + 测试 ≥45 + `npm run build` 产出
  `out/index.html`（根编排 `build:all` 硬性校验）。
- **R3**：QA、平衡、文案润色、zip 发布。
- **MoSCoW**：命星棋盘/因果/三道 = MUST；手谈 = SHOULD（可降级为纯事件）；
  酿酒篆符 = COULD（时间不足直接砍，坊市代偿）。
- **红线**：不得引入服务端 API；不得让隐藏机缘值进入任何 UI 字符串；
  事件文案不得整段抄录原著文本（致敬用意象与称谓，不用原文）。
