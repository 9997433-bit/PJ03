# G3 Brief — 《道君》人生模拟器(`games/dao-jun/`)

> 原著:萧舒。基调:**道纹为骨、神魂为刃、斗法为日常、道途抉择定终身**。
> 高举高打的正统仙侠:宗门林立、法会斗法、悟道刻纹;修的不只是力量,是「道」本身。
> 玩家是一名初入宗门的记名弟子,肉身与神魂两条腿走路,一步步走出自己的道。

## 叙述者与语气

叙述者:**道尊**(庄重、简峻、偶有机锋的宗门祖师口吻)。与前三作区分:天道漠然、弈者温和、司命精确,道尊则**评点式**——每逢抉择,他丢下一句公案(「剑冷,心不可冷」),不给答案。
文风:古雅峻拔,斗法场面浓墨重彩(全四作中战斗描写最重的一款)。

## 签名机制(全要)

### M1 · 双轨修行:肉身 × 神魂(核心差异化)
- **两条独立 exp 轨**:`bodyExp`(肉身境)与 `soulExp`(神魂境),各自升阶;角色总境界取两者较低者(短板制)。
- `修炼` 指令带参数(炼体 / 炼魂 / 双修——双修各得 60%);事件/丹药分别作用两轨。
- **失衡惩罚**:两轨相差 ≥ 2 阶触发「道基不稳」状态(突破率 −15%,心魔 DC +3),差 ≥ 3 阶时每回合掉血——机制上强迫玩家规划,而非无脑单点。
- 专项测试:短板制总境界、失衡状态挂载/解除、双修分账。

### M2 · 道纹镌刻(构筑系统)
- 替代炼丹的生产系统:**刻纹台**。道纹分四品(凡纹/灵纹/真纹/道纹),来源:悟道事件、斗法夺取、拓印遗迹。
- **三个刻纹槽**(兵刃/护体/神魂),刻入耗回合 + 检定(悟性),失败纹碎。
- **道意共鸣**:特定双纹组合激活套装效果(数据驱动 `resonances.ts`,≥ 8 组),例:雷纹+锋纹 =「霆锋」(强攻附加眩晕判定)。
- 专项测试:槽位约束、共鸣激活/失活、刻纹失败销毁。

### M3 · 道途抉择(分支锁定)
- 每逢**大境界突破成功**,道尊设问,三选一道途:**剑道 / 丹道 / 符道 / 体道 / 魂道**(逐层出现三项,种子化抽选);选定即永久:解锁专属指令与事件池、**锁死**相斥内容(剑修不得再选丹道主修)。
- 道途组合(3 次抉择 → 路径向量)直接映射结局分支:≥ 4 个结局由道途路径触发(剑绝天下 / 丹圣 / 符祖 / 杂而不纯)。
- 隐藏属性:**道缘**(暗掷,标记 `藏机`),门控高品道纹掉落与顿悟事件。
- 专项测试:抉择永久性、相斥锁、路径→结局映射。

## 领域模型

- 属性五维:**根骨 / 悟性 / 心性 / 神识 / 道缘(隐藏)**。神识参与神魂检定与斗法先手。
- 境界(双轨同梯):开脉(9 层)→ 灵台 → 法相 → 洞虚 → 道君(victory:双轨大圆满 + 三道归一)。
- 战斗换皮:**斗法**是本作核心景观 —— 战术:`力破`(强攻)/`周旋`(游斗)/`纹锁`(以护体纹布局,替代设伏)/`神魂击`(耗神识,无视护体纹)/`服丹`/`遁遁`→`破空`(遁走);敌方也持道纹,**纹克关系**(五行相克表)先手判定,UI 明示克制箭头。
- 经济:货币**玄玉**;市场称「法会」(定期事件型市场:每 8 回合开一次,货架轮换+竞拍事件);生产 = 刻纹台。

## 内容门槛

- 事件 ≥ 40:宗门大比、法会竞拍、遗迹拓纹、师兄斗法挑战、悟道石前枯坐、魔修渗透。≥ 5 条旗标链(建议:「残缺道纹复原」链、「同门宿敌」三战链、「祖师传承」链)。
- 结局 ≥ 10 全接线,建议:证道道君(victory)、剑绝天下、丹圣、符祖、杂道无成、神魂俱灭(失衡致死)、兵解转世、斗法陨落、寿终、走火、宗门叛徒(魔修线)、纹噬(道纹反客为主,彩蛋)。
- NPC ≥ 8:掌教、剑峰首座、丹阁长老、宿敌师兄、藏经阁老人……
