# G2 Brief — 《灭运图录》人生模拟器(`games/mieyun-tulu/`)

> 原著:爱潜水的乌贼(早期作品)。基调:**命运可量化、劫数可推演、修行是理性工程**。
> 主角式幻想:身怀能匿藏气数、推演功法的至宝,在「天数已定」的世界里给自己算出一条活路。
> 玩家扮演一名偶得残页《灭运图录》的散修——天机看得见你,但看不清你。

## 叙述者与语气

叙述者:**司命**(记账式、冷静、精确到数字的官僚腔)。与根游戏「天道」的区别:天道是漠然的旁观者,司命是**照章办事的执行者**——它会提前公示劫数(「三载之后,金火之劫,应于汝身」),从不隐瞒,也从不通融。
文风:公文+星象术语,凶事写得像判决书。

## 签名机制(全要)

### M1 · 劫运日历(核心差异化)
- **命盘视图**(独立标签页):未来 12 回合的时间轴,已定劫数以星官图钉标出(种子化生成 + 境界推进追加)。
- 每个「劫」= 定时触发的强制事件(战斗/心魔/天灾三型,各带评级 一~九劫)。**玩家提前可见、可备**:囤药、刻符、改命(M3)。到期未化解按判决执行。
- 渡劫成功 → 气数上涨 + 修为大进;失败 → 重伤/陨落(劫级越高死亡率越高)。
- 专项测试:日历生成确定性、劫到期必触发、化解路径各自生效。

### M2 · 推演功法(生产系统换皮)
- 替代炼丹:消耗**悟性检定 + 静室回合 + 图录残页**,把已有功法**推演升品**(黄→玄→地→天)或衍生新术。
- 推演树数据驱动(`derivations.ts`):前置功法 + 材料 + 基础成功率;大成功产出「本命化」版本(专属加成)。失败浪费回合但累积「推演心得」pity 计数(对照根游戏突破保底模式)。
- 专项测试:树前置约束、pity 递增、品阶上限。

### M3 · 匿运与改命(隐藏属性玩法反转)
- 可见资源:**气数**(0–100,事件效果字段 `fateValue`);隐藏属性:**命格**(暗掷,门控天命事件,标记 `匿运`)。
- **匿运**(自由指令,开关态):烧灵石维持,期间事件掷的气运偏移归零、劫运日历**冻结不新增**、但修为收益 −20% ——「天机看不见你,机缘也找不到你」。开/关各入审计。
- **改命**(高消耗指令):对日历上指定的劫发起 D100 对赌(气数加成),成功把劫**转嫁/延期/降级**(审计理由「改命·转嫁」),失败劫升一级。≥ 2 个结局由改命次数触发(逆天改命 / 反噬)。
- 专项测试:匿运期偏移归零、日历冻结、改命三种结果转移正确。

## 领域模型

- 属性五维:**根骨 / 悟性 / 心性 / 气数 / 命格(隐藏)**。
- 境界(取经典内丹阶梯,与凡人体系文字零重合):
  炼精化气(9 重)→ 炼气化神 → 阳神 → 炼神返虚 → 合道(victory:斩断命数,跳出图录)。
- 战斗换皮:**斗法如布阵** —— 战术:`雷法`(强攻)/`卦步`(游斗)/`布阵`(设伏)/`神通`(术法)/`服丹`/`遁空`(遁走);敌方带「命数克制」标签(与玩家当前劫属性生克,伤害 ±15%)。
- 经济:货币**道功**(宗门贡献式);墟市称「万法坊」;物品线偏符箓/阵盘/残页。

## 内容门槛

- 事件 ≥ 40:宗门任务、夺宝推演、星官示警、同门倾轧、魔修夺舍、天机阁卜算(付费窥探日历更远 4 回合)。≥ 5 条旗标链(建议:「图录残页收集」链 3+ 页、「师门恩怨」链、「匿运被窥破」链)。
- 结局 ≥ 10 全接线,建议:合道灭运(victory)、劫火焚身(渡劫死)、命格反噬(改命失败累积)、傀儡天命(气数满但从不改命)、隐世算师、宗门柱石、夺舍失身、战死、寿终、走火入魔、图录圆满(集齐残页彩蛋)。
- NPC ≥ 8:掌门、星官、师姐、天机阁主、魔道说客……
