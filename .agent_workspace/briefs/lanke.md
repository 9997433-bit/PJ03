# G1 Brief — 《烂柯棋缘》人生模拟器(`games/lanke-qiyuan/`)

> 原著:真费烟。基调:温和修仙、文人烟火气、棋道喻命、游历江湖、因果善缘。
> 「烂柯」典出:樵夫观仙人对弈,一局未终,斧柯已烂——**棋即岁月,子即众生**。
> 玩家不是原著主角,而是这个「有鬼神狐妖、有书生老龙」的世界里一名新入道者。

## 叙述者与语气

叙述者:**弈者**(执子的无名仙人,温和、含蓄、带书卷气)。与根游戏「天道无情」形成对照:弈者会惋惜、会莞尔,但从不出手干预——「子已落,不复移」。
文风:白描 + 淡淡的市井暖意(茶棚、灯会、渡口、书院),凶险事件也收着写。

## 签名机制(必做,三选一不可,全要)

### M1 · 棋盘天机(核心差异化)
- 全局一张 **9×9 命理棋局**(独立视图,替代根游戏「炼丹」标签页)。
- 玩家通过善缘事件获得**白子**、因果纠葛获得**黑子**(资源,入库存但不占背包)。
- **落子**(耗一回合,审计掷定位微偏):白子落于某「星位」→ 未来 N 回合事件掷向吉桶偏移/指定 NPC 线解锁;黑子落下 → 换取即时大利但埋「劫」旗标(后续凶事件链)。
- 棋局盘面入存档;每一次落子入审计(理由「落子·天元」等)。
- 数据完整性测试:星位表覆盖、偏移量有界(防不变量违规)。

### M2 · 烂柯观弈(时间跳跃)
- 稀有事件「山中观弈」(大吉桶,机缘门):选择观完一局 → **一次跳过 4–12 回合**(审计掷),修为大涨、却直接消耗等量寿元、期间世界事件照常结算(NPC 好感衰减、任务超时)。「一局烂柯,人间数载」。
- 专项测试:跳跃后年龄/寿元/任务状态一致性。

### M3 · 因果簿(善恶双轨)
- 可见双计数:**善缘 / 业障**(替代根游戏单一隐藏机缘;本作隐藏属性改为「慧根」,暗掷产生,门控顿悟类事件)。
- 事件效果新增 `karma: ±n`;善缘高解锁温情结局线与 NPC 相助,业障高触发讨债/心障事件链。
- ≥ 3 个结局直接由善恶阈值触发。

## 领域模型

- 属性五维:**根骨 / 悟性 / 心性 / 棋力 / 慧根(隐藏)**。棋力参与对弈检定与落子精度。
- 进阶体系(修行 + 棋道双标尺,单一 exp,双标签展示):
  凡俗 → 引气(9 层)→ 凝真 → 玄光 → 洞明 → 登仙(victory 门)。
  另设**棋品九段**(以对弈胜局与观弈累积,门控落子权限:低段只能落边角,高段可落天元)。
- 战斗换皮:**斗法如对弈** —— 战术:`先手`(强攻)/`缠斗`(游斗)/`弃子`(牺牲物品换先机,替代设伏)/`妙手`(术法)/`服药`/`收枰`(遁走)。
- 经济:货币**文钱+灵砂**双币(市井/修行两层);集市称「墟市」,生产系统为**手谈授业**(教棋换钱与善缘,替代炼丹)。

## 内容门槛(对照 SOTA_CRITERIA)

- 事件 ≥ 40:市井温情(灯会、赠伞、义诊)、鬼狐奇谭(狐求字、鬼托梦)、棋事(茶楼赌棋、盲棋老者)、凶险(山魈、水匪)。≥ 5 条旗标链(建议:「烂柯洞」链、「狐仙报恩」链、「书生赶考」链)。
- 结局 ≥ 10 全接线,建议:登仙、坐忘烂柯(观弈至寿尽,特殊「安详死」)、棋圣(棋品九段+洞明)、守灯人(善缘极高止步低境)、业火焚身(业障满)、江湖再见(游历成痴)、战死、寿终、走火、心障、误入棋局(彩蛋)。
- NPC ≥ 8:落魄书生、狐妖学徒、江中老龙、茶棚老板娘、云游僧、赌棋浪子……好感阈值解锁支线。
